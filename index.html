Operational scope

      
This is an electronic OFP / Journey Log filling and formatting tool only.
      It does not replace the issued or approved OFP, SOP, current flight-information sources,
      or airline-approved EFB applications. Weather, NOTAM and chart views duplicate information
      from the loaded package for document navigation only and must not be used as the source for
      operational decisions.


      
Install once

      
Open this page in Safari, then tap Share → Add to Home Screen → Add.
      Launch it once before departure to make it available offline.

      
    
        
  1. Use the home-screen app, not a Files preview: saving and sharing work reliably there.
    2. 
        
  2. Keep the version you have checked before departure; an offline app does not update.
    3. 
        
  3. When connected, a new version offers Update now. It updates only when you choose it.
    4. 
      


      
Before flight

      
    
        
  1. Load the Air Astana OFP PDF and check the route ID, request number and release time in the header.
    2. 
        
  2. Complete document fields such as ATIS, ATC clearance, altimeter settings and PIC BLOCK.
    3. 
        
  3. Enter the takeoff time in UTC as four digits. The ETD button uses the planned off-block time, so verify it before use.
    4. 
        
  4. Read the ICAO flight plan, weather, NOTAMs and charts from the package as required.
    5. 
      


      
In flight

      
    
        
  • Enter actual ATO and remaining fuel at each waypoint. Next and Previous move through the entry fields.
    • 
        
  • Record fuel checks at an overflown waypoint or at least every 30 minutes. Amber means due soon; red means overdue.
    • 
        
  • Complete the altimeter cross-checks when due. The app highlights overdue items and asks before saving with missing checks.
    • 
        
  • For a clearance direct, use Direct to…; it updates the live highlight only and never rewrites the planned ETOs.
    • 
      


      
Weather, charts and saving

      
Weather, NOTAMs and charts are read from the loaded package; they are not live data.
      Re-brief from the current operational source before acting on them. Save PDF opens
      the share sheet for Files, AirDrop, Print or ForeFlight. ETO is blue, ATO is green, and
      fuel is black in the saved document.


      
Data and limits

      
Everything is processed on the device and saves automatically for the current plan.
      Reset permanently removes the plan and its entries. Only supported Air Astana
      computerized OFPs can be loaded.


      
Release candidate versions

      
RC1 is the first release candidate. Bug fixes and small refinements use
      RC1.1, RC1.1.2, RC1.2 and so on. Major changes move to
      RC2, RC3 and later release candidates until the final release.
